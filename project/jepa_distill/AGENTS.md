# JEPA distill

## structure
- `jepa_distill/` main parent folder for planning, execution and some independent modules
- `design_doc/` folder for method doc, implementation doc, other agent execution docs 
- create other folder as needed to keep the structure clean, organized and intuitive for human user to understand

## coding standards
- the implementation of this idea may touch existing code. it should not alter existing behavior, and should not break existing code. but at the same time the addition should be clean, organized and intuitive for human user to understand not wrapped in a mess of code.
- keep the implementation really clean, and easy. the existing pufferdrive and pufferlib was implemented in such a way so use that as a style guide when making choices. 
- only add minimal code to implement the idea, and keep the code clean and organized.

## on working with human user
- make sure keep good documentation and explanation of idea. that is design_doc folder was created for, but do not make long-winded explanation, keep it short and concise.
- make sure to keep the human user in the loop, and ask for clarification if needed.

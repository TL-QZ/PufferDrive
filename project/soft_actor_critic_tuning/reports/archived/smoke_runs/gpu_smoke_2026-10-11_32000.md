# SAC smoke with PPO's 32,000-row microbatch — 2026-10-11

Archived smoke validation. Settings and paths describe the historical check.

**Passed:** SAC now uses `train.max_minibatch_size: 32000`, matching the CARLA
nightly PPO launcher. `train.minibatch_size` remains 128,000 per rank. Each
critic and actor optimizer update accumulates four chunks, instead of the
previous 16; the logical update count and epoch count are unchanged.

The smoke helper inherits the configured microbatch size instead of overriding
it. The launch guide reflects the new setting. Other experiment settings and
the 16-trial grid are unchanged.

## Real two-GPU verification

```bash
bash project/soft_actor_critic_tuning/scripts/launch_sweep.sh \
  --smoke --gpu-pairs '0,1' --max-concurrent 1 \
  --output-dir project/soft_actor_critic_tuning/runs/gpu_smoke_32000_20261011
```

W&B, Neptune, TensorBoard, and model uploads were disabled; child processes
received `WANDB_MODE=disabled`. The generated config confirmed a 128,000-row
logical minibatch and 32,000-row microbatches. The test retained the real Drive
environment, full actor and twin critics, two-rank DDP, BF16, and CPU replay.
Replay capacity was reduced to 128,000 per rank for this short test.

| Measurement | Result |
| --- | --- |
| Exit / status / stop reason | `0` / `completed` / `deadline` |
| Complete collection/training cycles | 5 |
| Logical learner updates per rank | 15 |
| Received agent rows, global | 390,400 |
| Sampled training transitions, global | 3,840,000 |
| Peak allocated CUDA memory, rank 0 / 1 | 17.233 / 17.235 GiB |
| Peak reserved CUDA memory, rank 0 / 1 | 23.117 / 23.125 GiB |
| Maximum one-second sampled device memory, GPU 0 / 1 | 24,245 / 24,253 MiB |
| Maximum sampled compute utilization, both GPUs | 100% |
| Final critic / policy / temperature loss | 0.186249 / 0.156171 / -0.110131 |
| Recorded cumulative training section | 49.75 seconds |
| Whole trial, including startup and shutdown | 83.71 seconds |

All five metric records had finite losses. Both rank runtime records had no
errors. The actor and learner checkpoints were present and nonempty, with no
missing artifacts. After shutdown, `nvidia-smi` showed no active CUDA processes.

The [previous 8,192-row smoke](gpu_smoke_2026-10-11.md) recorded 52.08 seconds in
its training section for the same 15 updates. The new value was about 4.5%
lower in this single short comparison. Whole-trial time was longer, so this is
not evidence of a measured end-to-end speedup. Peak compute utilization is not
an average throughput measurement.

Raw configs, metrics, rank runtime records, summaries, and checkpoints remain
under the ignored local directory
`project/soft_actor_critic_tuning/runs/gpu_smoke_32000_20261011/`. The GPU sampler
wrote `/tmp/pufferdrive_sac_32000_gpu_usage.csv`.

This qualifies the updated model/microbatch execution and shutdown on two A6000
GPUs. Full 8,192,000-entry replay initialization, production environment counts,
long-run learning quality, and W&B uploads were not exercised.
